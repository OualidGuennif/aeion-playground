What runs and what remains a contract

Be explicit about the evidence class.

Executed: model CLI calls when available, git diffs, pytest, SQLite FTS5, Graphify AST extraction, local Paperclip API, OPS integrity checker and CROA structure audit.

Deterministic: pricing rule, gate decisions, check counts, evidence binding, task identity.

Not claimed: a production security boundary, a CROA certification, OS isolation, a collector, Hindsight or a GitHub release.

Next: qualify each additional integration against its own contract before claiming it is active.

Run it locally

Mission Control on port 8123; Paperclip is a separate local service.

cd POC_AEION
./run.sh
# open http://127.0.0.1:8123

Missions persist in runtime/aeion.db; events are projected to runtime/events.jsonl. Reset is disabled to preserve the ledger.
